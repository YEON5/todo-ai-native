# 수용 기준 (Acceptance Criteria)

각 기준은 Given-When-Then 형식입니다. "검증" 열은 확인 방법입니다.
- `API`: pytest
- `UI`: 브라우저 수동 또는 자동 확인
- `빌드`: `npm run build` / `npm run lint`

## FR-001 할 일 생성

| ID | Given | When | Then | 검증 |
| --- | --- | --- | --- | --- |
| AC-001-1 | 목록이 비어 있다 | 제목 "운동 30분"으로 추가한다 | 201과 `completed: false`인 Todo가 반환되고, 화면 목록 맨 아래에 보인다 | API, UI |
| AC-001-2 | — | 제목 `"  운동  "`으로 추가한다 | 저장된 제목은 `"운동"`이다 | API |
| AC-001-3 | — | 빈 문자열 또는 공백만 있는 제목으로 추가한다 | API는 422를 반환하고, 화면에서는 추가 버튼이 비활성화되어 요청이 가지 않는다 | API, UI |
| AC-001-4 | — | 201자 제목으로 추가한다 | 422를 반환한다. 200자는 성공한다 | API |
| AC-001-5 | 입력창에 포커스가 있다 | 제목을 적고 Enter를 누른다 | 할 일이 추가되고 입력창은 비워지며 포커스가 입력창에 남는다 | UI |

## FR-002 목록 조회

| ID | Given | When | Then | 검증 |
| --- | --- | --- | --- | --- |
| AC-002-1 | A, B, C 순서로 생성했다 | 목록을 조회한다 | 200과 `[A, B, C]` 순서(`created_at` 오름차순)로 반환된다 | API |
| AC-002-2 | 할 일이 없다 | 목록을 조회한다 | `[]`가 반환되고, 화면에는 "아직 할 일이 없어요."가 보인다 | API, UI |

## FR-003 제목 수정

| ID | Given | When | Then | 검증 |
| --- | --- | --- | --- | --- |
| AC-003-1 | 할 일 A가 있다 | `{ "title": "A2" }`로 PATCH한다 | 200과 제목이 "A2"인 Todo가 반환되고, `completed`는 그대로다 | API |
| AC-003-2 | 할 일 A를 편집 중이다 | 제목을 바꾸고 Enter를 누른다 | 저장되고 포커스가 A의 수정 버튼으로 돌아온다 | UI |
| AC-003-3 | 할 일 A를 편집 중이다 | Esc를 누른다 | 제목이 바뀌지 않고, 요청도 보내지 않으며, 포커스가 수정 버튼으로 돌아온다 | UI |
| AC-003-4 | — | 공백 제목으로 PATCH하거나 빈 본문 `{}`로 PATCH한다 | 422를 반환한다 | API |
| AC-003-5 | — | 없는 id로 PATCH한다 | 404를 반환한다 | API |

## FR-004 완료 상태 변경

| ID | Given | When | Then | 검증 |
| --- | --- | --- | --- | --- |
| AC-004-1 | 미완료 할 일 A가 있다 | `{ "completed": true }`로 PATCH한다 | 200과 `completed: true`가 반환되고, 제목은 그대로다 | API |
| AC-004-2 | 체크박스에 포커스가 있다 | Space를 누른다 | 완료 상태가 바뀌고 취소선이 표시되며 완료율이 갱신된다 | UI |
| AC-004-3 | A를 완료로 바꿨다 | 페이지를 새로고침한다 | A가 여전히 완료 상태다 | UI (FR-007) |

## FR-005 삭제

| ID | Given | When | Then | 검증 |
| --- | --- | --- | --- | --- |
| AC-005-1 | A, B, C가 있다 | B를 DELETE한다 | 204가 반환되고, 이후 목록은 `[A, C]`다 | API |
| AC-005-2 | — | 없는 id(이미 삭제된 id 포함)로 DELETE한다 | 404를 반환한다 | API |
| AC-005-3 | 화면에 A, B, C가 있다 | 키보드로 B를 삭제한다 | B가 사라지고 포커스가 C의 체크박스로 이동한다. 마지막 하나를 지우면 입력창으로 이동한다 | UI |

## FR-006 완료율 표시

| ID | Given | When | Then | 검증 |
| --- | --- | --- | --- | --- |
| AC-006-1 | 4개 중 2개가 완료다 | 화면을 본다 | "50%", "4개 중 2개 완료", 진행 막대 4칸 중 해당 2칸이 채워져 있다 | UI |
| AC-006-2 | 할 일이 없다 | 화면을 본다 | "0%"와 "첫 할 일을 추가해 보세요"가 보인다 | UI |

## FR-007 데이터 영속성

| ID | Given | When | Then | 검증 |
| --- | --- | --- | --- | --- |
| AC-007-1 | 할 일을 추가·수정·삭제했다 | 페이지를 새로고침한다 | 마지막 상태가 그대로 보인다 | UI |
| AC-007-2 | Supabase 저장소를 쓰고 있다 | 백엔드 서버를 재시작한다 | 목록이 그대로 유지된다 | API, UI |
| AC-007-3 | In-Memory를 Supabase 저장소로 바꿨다 | AC-001~005의 API 테스트를 다시 실행한다 | 모두 PASS다(응답 형식이 같다) | API |

## FR-008 로딩·오류 표시

| ID | Given | When | Then | 검증 |
| --- | --- | --- | --- | --- |
| AC-008-1 | 백엔드가 응답하지 않는다 | 앱을 연다 | 로딩 표시 뒤에 "할 일을 불러오지 못했어요"와 다시 시도 버튼이 보인다 | UI |
| AC-008-2 | 백엔드가 꺼져 있다 | 할 일을 추가한다 | 목록에 추가되지 않고, 입력한 내용이 입력창에 남으며, 오류 메시지가 보인다 | UI |
| AC-008-3 | 오류 메시지가 보인다 | 다시 시도 버튼을 누르고 서버가 정상이다 | 목록이 표시되고 오류 메시지가 사라진다 | UI |

## FR-009 마감일 등록·수정

| ID | Given | When | Then | 검증 |
| --- | --- | --- | --- | --- |
| AC-009-1 | — | 마감일 없이 `{ "title": "A" }`로 생성한다 | 201과 `due_date: null`인 Todo가 반환되고, 카드에는 마감일이 표시되지 않는다 | API, UI |
| AC-009-2 | — | `{ "title": "A", "due_date": "2026-11-28" }`로 생성한다 | 201과 `due_date: "2026-11-28"`이 반환되고, 목록 조회에도 같은 값이 나온다. 카드에는 "마감 11월 28일 (토)"가 보인다 | API, UI |
| AC-009-3 | 마감일이 `2026-11-28`인 할 일 A가 있다 | `{ "due_date": "2026-11-30" }`로 PATCH한다 | 200과 새 마감일이 반환되고, 제목·완료 상태는 그대로다 | API |
| AC-009-4 | 마감일이 있는 할 일 A가 있다 | `{ "due_date": null }`로 PATCH한다 | 200과 `due_date: null`이 반환된다(마감일 지우기) | API |
| AC-009-5 | 마감일이 있는 할 일 A가 있다 | `{ "title": "A2" }` 또는 `{ "completed": true }`로 PATCH한다 | 마감일이 바뀌지 않는다 | API |
| AC-009-6 | — | 마감일을 `2026-02-30`, `2026/11/28`, `2026-11-28T00:00:00`, `20261128`(숫자), `true`로 생성하거나 수정한다 | 모두 422이고 데이터가 바뀌지 않는다 | API |
| AC-009-7 | — | 지난 날짜(`2020-01-01`)로 생성한다 | 201로 저장된다 | API |
| AC-009-8 | 입력 카드에 제목과 마감일을 입력했다 | Enter를 누른다 | 할 일이 추가되고 카드에 마감일이 보인다. 제목과 마감일 입력칸이 모두 비워진다 | UI |
| AC-009-9 | 할 일 A를 편집 중이다 | 마감일을 바꾸거나 비우고 Enter로 저장한다 | 카드의 마감일이 바뀌거나 사라지고, 포커스가 A의 수정 버튼으로 돌아온다. Esc로 취소하면 바뀌지 않는다 | UI |
| AC-009-10 | 마감일을 지정했다 | 페이지를 새로고침한다 | 마감일이 그대로 보인다 (FR-007) | UI |
